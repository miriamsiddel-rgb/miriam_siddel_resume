HydroMATE: AI-Integrated Automation

Holmesglen capstone project

I rebuilt a broken customer support intake process as three progressively advanced Make workflows. The first captures an enquiry through a webhook, normalises it, and logs it with a ticket ID. The second adds a Google Gemini step that classifies each enquiry by priority and type, using a narrow prompt with a fixed output format and a default to High when unsure, so the failure is safe rather than silent. The third adds conditional routing that escalates urgent enquiries to a specialist Telegram channel in real time, with a Gmail fallback. When the Telegram integration failed in testing, I used the vendor documentation to trace and fix it. The principle throughout was that automation routes and people resolve.

Make Webhooks Google Gemini Conditional Routing Telegram Integration
